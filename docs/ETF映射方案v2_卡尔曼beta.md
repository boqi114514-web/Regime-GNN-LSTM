# ETF 映射方案 v2：卡尔曼 Beta 行业代理选择

## 背景与目标

模型输出申万一级行业轮动信号，需要找到对应的 ETF 作为执行载体。

v1（成份股重叠纯度）的问题：纯度优先导致选出细分主题 ETF（如半导体设备ETF、创新药ETF），覆盖度太低，不能代表整个行业。

v2 核心思想：**不看成份，看价格行为**。ETF 月收益率对申万行业月收益率做卡尔曼 beta 估计，找到行业的"价格代理"而非"成份代理"。

---

## 方法论

### 模型

```
R_ETF(t) = α + β(t) × R_行业(t) + ε(t)
```

β(t) 用卡尔曼滤波估计（时变），复用 s4_beta_selection.py 中的 `kalman_beta_daily` 结构，改为月频：

**状态向量：** `x = [α, β]`

**预测步：**
```
beta_prior = γ × beta_{t-1} + (1 - γ) × 1.0   # ETF无基本面，先验锚定在1
x_pred = [α, beta_prior]
P_pred = P + Q
```

**更新步：**
```
H = [1, R_行业(t)]
K = P_pred @ H / (H @ P_pred @ H + R_noise)
x = x_pred + K × (R_ETF(t) - H @ x_pred)
P = (I - K⊗H) @ P_pred
```

**月频参数调整（相比日频）：**

| 参数 | 日频（s4） | 月频（本方案） | 说明 |
|------|-----------|--------------|------|
| gamma | 0.95 | 0.85 | 月频观测少，惯性适当降低 |
| Q_beta | 1e-5 | 1e-3 | 允许 beta 月间有一定变化 |
| Q_alpha | 1e-6 | 1e-4 | 同上 |
| R_noise | 1e-3 | 5e-3 | 月收益噪声比日频大 |
| 最少观测 | 30天 | 18个月 | 约1.5年历史才估 |

## 筛选与排序标准

### 第一步：候选池过滤
- 规模 > 5亿（`etf_share_size`，已有缓存）
- 境内ETF（已有缓存 `_cache_etf_basic.pkl`）
- 月度观测数 ≥ 18

### 第二步：卡尔曼 beta 计算
对每个 (ETF, 申万行业) 组合，输出：
- `beta_last`：最新一期 beta 估计值
- `beta_std`：近24个月 beta 的标准差（稳定性指标）
- `R2`：样本内拟合优度（行业因子解释 ETF 方差的比例）

### 第三步：筛选条件
```
beta_last > 0          # 方向一致（排除反向/无关ETF）
R2 > 0.70             # 行业是主要驱动因子
beta_std < 0.3        # beta 稳定，无风格漂移
```

### 第四步：排序
```
主排序：R2 降序          # 行业解释力越强越好
次排序：beta_last 降序   # 同等R2下，beta大的优先（更敏感）
三排序：规模 降序        # 流动性
```

> **不设 beta 上限**：β > 1 说明 ETF 对行业更敏感，方向正确时收益更大，符合行业轮动的使用场景。

## 与 v1 的对比

| 维度 | v1（成份股纯度） | v2（卡尔曼 beta） |
|------|----------------|-----------------|
| 核心逻辑 | 成份股重叠比例 | 收益率价格行为 |
| 主要问题 | 细分主题ETF纯度高但覆盖窄 | 需要历史价格数据 |
| 对新ETF | 上市即可评估 | 需18个月历史 |
| 与目标对齐 | 间接（成份→收益） | 直接（收益→收益） |
| β>1的ETF | 可能被排除 | 保留并优先 |

**全量计算策略：** 不做任何预筛（不按规模、不按成份重叠），对全部 ~2700 只境内 ETF × 31 个申万行业全量跑卡尔曼，共约 **60000+ 对**。

- 卡尔曼本身是 2×2 矩阵运算，60000 对 × 60 月 ≈ 仍是秒级，不是瓶颈
- 真正的耗时是一次性拉全部 ~2700 只 ETF 的日线价格（`fund_daily` + `fund_adj`），拉完缓存即可
- 全量跑的好处：不遗漏任何潜在代理，规模筛选留到最后输出阶段做，选股逻辑与数据获取解耦
